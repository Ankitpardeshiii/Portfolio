BangaBites

Smart Restaurant Recommendation System for Bengaluru

BangaBites is a deployed content-based restaurant recommendation system focused on Bengaluru restaurants. It recommends restaurants similar to a user's selected restaurant using TF-IDF and Cosine Similarity, while also considering weighted rating, popularity, and budget compatibility.

  • Content-based recommendations with TF-IDF & Cosine Similarity
  • Weighted ratings, popularity & budget scoring
  • Location filtering, minimum rating & max budget controls
  • Zomato restaurant links & responsive web interface
  • Cloud-deployed Flask REST API on Render

AI-assisted development was used to accelerate frontend/UI implementation and Flask integration, while the recommendation logic, data processing, scoring system and overall project architecture were designed and integrated as part of the project.
